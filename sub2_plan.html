🏋️ Push / Pull / Leg

📘 พื้นฐานเวท + การหายใจ

🫁 หายใจตอนยกเวท
กฎข้อเดียว: ออกแรง = หายใจออก · คืนท่า = หายใจเข้า · ห้ามกลั้นหายใจค้างหลาย reps
ท่าหายใจเข้าหายใจออก
Squat / Split Squatตอนย่อลงตอนดันขึ้น
RDLตอนก้มลงตอนยืดตัวขึ้น
Push-up / Pressตอนลงตอนดันขึ้น
Row / Pull-up / Curlตอนปล่อยลงตอนดึงเข้า/ขึ้น
Negative pull-upก่อนเริ่มลงปล่อยออกช้าๆ ระหว่างลง
เกร็งแกนกลาง (bracing): ก่อนแต่ละ rep หายใจเข้าให้ท้องและซี่โครงขยายรอบตัว (ไม่ใช่ยกไหล่) → เกร็งท้องเหมือนกำลังจะโดนจิ้มพุง แรงประมาณ 30-50% → ทำ rep แล้วค่อยหายใจออก
🧱 หายใจตอนทำ core
• Plank / Side Plank: หายใจสั้นๆ สม่ำเสมอ เกร็งท้องค้างไว้ระหว่างหายใจ · ทดสอบ: ถ้านับเลขออกเสียงได้ = หายใจถูก
• Dead Bug / Bird Dog: หายใจออกยาวๆ ตอนเหยียดแขนขาออก ให้ซี่โครงยุบลง หลังล่างแนบพื้น · หายใจเข้าตอนดึงกลับ
• Glute Bridge / Knee Raise: หายใจออกตอนยกขึ้น หายใจเข้าตอนลง
• ถ้าเริ่มกลั้นหายใจหรือหน้าแดง = ท่ายากไป ลดเวลา/ลดระดับลงก่อน
🏃 หายใจตอนวิ่ง
ความหนักจังหวะ (ก้าวเข้า : ก้าวออก)เช็ค
Easy / Long3 : 3พูดเป็นประโยคได้
Threshold / Fartlek2 : 2พูดได้ทีละ 2-3 คำ
ช่วงเร่งท้าย / แข่งสั้น2 : 1พูดไม่ได้
• หายใจทางปาก + จมูกพร้อมกันได้ ไม่ต้องบังคับจมูกอย่างเดียว · หายใจลงท้อง ไหล่ปล่อยสบาย
• จุกเสียด: ชะลอ → หายใจออกแรงๆ ยาวๆ → กดจุดที่เจ็บ แล้วค่อยกลับมาเร่ง
• ตอนเริ่มเกร็ง (เหมือนวันแข่งที่เท้าชา): หายใจออกยาว 2-3 ครั้ง ปล่อยไหล่ คลายมือ แล้วเช็คเท้า
📖 คำศัพท์ในตาราง
• Rep = ทำ 1 ครั้ง · Set = ทำต่อเนื่องหลาย reps แล้วพัก · "3 × 12" = 3 เซ็ต เซ็ตละ 12 ครั้ง
• /ขา, /ข้าง = จำนวนนี้ต่อข้าง ซ้ายครบแล้วทำขวา
• เกือบหมดแรง = หยุดตอนรู้สึกว่าทำได้อีกแค่ 1-3 ครั้ง (ไม่ต้องทำจนท่าเสีย)
• ลงช้า 3 วิ = นับ 1-2-3 ตอนลง แล้วขึ้นตามปกติ · ค้าง 2 วิ = หยุดนิ่งตรงจุดนั้น
• Superset (SS) = ทำ 2 ท่าต่อกันไม่พัก แล้วค่อยพัก
• พัก = จับเวลาหลังจบเซ็ต (หรือหลังจบคู่ superset)
✅ ท่าทาง + ความปลอดภัย
• หลังตรงตามธรรมชาติ ไม่ห่อ ไม่แอ่น · เข่าชี้ไปทางเดียวกับปลายเท้า ไม่หุบเข้าใน
• ท่าเสีย = จบเซ็ตนั้นเลย แม้ยังไม่ครบ reps
• เมื่อยกล้ามเนื้อ 1-2 วันหลังเล่น (โดยเฉพาะ 2 สัปดาห์แรก) = ปกติ · เจ็บแปลบที่ข้อ/เอ็น = หยุดท่านั้น
• เริ่มเบาไว้ก่อน 2 สัปดาห์แรกทำแค่ 2 เซ็ต
