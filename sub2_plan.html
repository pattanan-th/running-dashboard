🔑 ตั้งค่าการ Save (ครั้งเดียวต่อเครื่อง)
1. เปิด github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
2. Repository access: Only select repositories → running-dashboard
3. Permissions → Repository → Contents: Read and write (อย่างเดียวพอ) · ตั้งวันหมดอายุตามสะดวก
4. คัดลอก token มาวางด้านล่าง → กดเก็บ · token อยู่ในเครื่องนี้เท่านั้น ไม่ขึ้นเว็บ/ไม่เข้า repo
ทำซ้ำในมือถือและคอมเครื่องละครั้ง · มือถือหาย → Revoke token ใน GitHub ได้ทันที
